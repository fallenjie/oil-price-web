# PRD-001: 国内油价走势网页

## 1. 概念与愿景

一个简洁、专业的国内油价展示页面，实时展示最新油价数据及走势曲线。界面风格偏向金融数据可视化，突出价格变动日期，让用户一眼看清油价涨跌趋势。

## 2. 用户故事

**作为** 普通车主/关注油价的用户  
**我希望** 快速看到今日油价和近期走势  
**以便** 了解油价变化，做出出行/加油决策

## 3. 功能需求

### 3.1 当日油价展示
- 显示 92号汽油 当前油价
- 单位：元/升
- 数字大而醒目

### 3.2 涨跌信息
- 相对上次调整的涨跌额（单位：元/升）
- 涨跌幅百分比
- 颜色区分：中国股市习惯（红涨绿跌）

### 3.3 趋势图
- X轴：日期（最近30天）
- Y轴：油价区间
- 普通日期：灰色圆点
- 价格变动日：**金色高亮点 + hover显示变动金额**

### 3.4 油价变动记录列表
- 列出调价记录
- 每条记录包含：日期、从xx→xx元、涨跌额

## 4. 数据要求

**⚠️ 关键要求：数据必须真实**
- 数据来源：国家发改委成品油价格调整公告
- 使用真实历史数据（2025年）
- 页面必须明确标注数据来源

## 5. 技术方案

- **单文件 HTML**：包含 CSS + JS
- **图表库**：Chart.js 4.x（CDN）
- **数据**：2025年真实调价记录
