# PRD-001: 国内油价查询页面 v2

## 1. 项目概述

一个简洁、专业的国内油价展示页面，**使用真实在线API获取数据**，实时展示最新油价数据及一个月走势曲线。界面风格偏向金融数据可视化，突出价格变动日期，让用户一眼看清油价涨跌趋势。

## 2. 用户画像

- **行为**：普通通勤者/关注油价的用户
- **需求**：快速查看油价和近期趋势
- **痛点**：想了解油价变化，合理安排加油

## 3. 功能需求

### 3.1 当日油价展示
- 展示 92号汽油 当前油价
- 单位：元/升
- 数据来源：真实API

### 3.2 涨跌信息
- 较上次油价变动（单位：元/升）
- 涨跌百分比
- **红涨绿跌**（中国股市惯例）

### 3.3 30天趋势图
- X轴：最近30天日期
- Y轴：油价区间
- 普通日期：灰色圆点
- **价格变动日**：高亮点（橙色+阴影+hover显示变动金额）

### 3.4 油价变动记录列表
- 列出本月所有油价调整
- 每条记录：日期、从xx元 → xx元，变动金额

### 3.5 统计数据
- 较上月价格
- 本月最高/最低价
- 本月平均价格

## 4. 技术规格

### 4.1 技术栈
- 单文件 HTML（包含 CSS + JS）
- Chart.js 4.x（CDN）
- **真实API获取数据**（非模拟数据）

### 4.2 API选择
- 优先使用免费可靠的油价API
- 如无合适免费API，可考虑：
  - 国家发改委官网数据
  - 国际油价+国内油价换算公式
  - 财经数据API

### 4.3 数据
- 使用真实API获取当前油价
- 30天历史数据（如API支持）
- 数据来源必须声明
