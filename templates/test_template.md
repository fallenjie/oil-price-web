### 2. 日期有效性检查（强制）

```
当前日期：2026-04-06
PRD 约定时间范围：近30天（应为 2026-03-06 ~ 2026-04-06）

检查项：
1. 实际数据的日期范围是什么？
2. 是否与 PRD 约定一致？
3. 数据年份是否正确（2026年而非2025年）？

如果日期范围错误 → FAIL
```

### 3. 数据来源检查（强制）

```
要求：代码或测试报告中必须声明数据来源

检查项：
1. 数据来源是否声明？（如：国家发改委官网）
2. 声明的数据是否与实际使用的一致？
3. 数据是否为真实数据而非虚构？

如果无数据来源或数据虚构 → FAIL
```
